## Effective product requirement

Provide one automatically discoverable `co-design-ui` skill inside the Johnny plugin. Starting
from a product goal, existing UI or plain design brief, it must help the owner compare materially
different visual directions, select and seal one target-owned UI regime, derive feature-level UI
contracts, and review implemented screenshots across required states and breakpoints.

No Figma account, external designer or design-craft provider is mandatory. When an authorized
Figma, image-generation or other design-craft capability exists, it contributes candidates or
audit findings only. When none exists, the workflow uses target-owned briefs, tokens, reference
markup and rendered screenshots. The owner remains the design decision maker.

## Non-negotiable properties

1. At least two proposed directions must differ in hierarchy, typography, density, component
   language and motion/interaction character; colour swaps are not distinct directions.
2. No direction becomes implementation authority until the owner explicitly selects it. The
   selected regime is sealed once and reused by later feature tickets.
3. Every feature contract covers loading, empty, success, validation error, system error,
   permission/disabled and relevant offline states, plus responsive and accessibility behavior.
4. Figma, image generation and design-craft tools are optional inputs. Their output is a candidate
   or finding, never approval, review conclusion or source authority.
5. The implementation owner does not approve its own visual result. Reviewer evidence includes
   actual rendered screenshots at declared breakpoints and an adversarial visual/accessibility
   pass before owner acceptance.
6. Generated design artifacts are target-owned and versioned; target runtime never imports from
   this plugin.

## Boundary

This draft authorizes no design-tool access, image generation, Figma write, UI source change,
implementation, publication, installation or release. Exact owner approval is required before the
first ticket is opened.
