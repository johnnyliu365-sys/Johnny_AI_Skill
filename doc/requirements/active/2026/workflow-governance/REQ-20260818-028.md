# Adaptive workflow intensity from typed workload assessment

| Field | Value |
| --- | --- |
| PRD / change | `PRD-20260818-028` / `CHG-20260818-028` |
| Lifecycle | `ACTIVE` |
| Old rule | Workflow intensity (`COMPACT`/`STANDARD`/`HIGH_ASSURANCE`) was assessed as unstructured prose judgment with no schema or evidence binding, and it did not change the workflow's shape: every project produced full per-stage artifacts, a full SPEC and the full review matrix regardless of size, so small changes paid the whole ceremony and the assessment was skippable in practice. |
| New rule | Intensity is derived, never asserted: a committed `WorkloadAssessment` (five evidence-backed signals, each with a fixed floor) feeds `derive_workflow_intensity()`, a deterministic maximum with no override input. The assessment travels in `NormalizedGoal.workload`; a missing assessment means minimum `STANDARD` and `COMPACT` is unclaimable. The derived intensity scales the workflow shape by a fixed table — combined discovery leaf, micro-SPEC and single ticket with focused review for `COMPACT`; per-stage artifacts for `STANDARD`; alternatives, threat matrix, adversarial review and reverse mutation for `HIGH_ASSURANCE` — while stage order and Router authority never change. `DELTA` + `COMPACT` is the declared minimal path. Upgrades are automatic on new evidence; downgrades need committed evidence plus owner approval. |
| Rationale | Owner requirement: the skill must adapt to project size and complexity. Fixed full-ceremony overhead made the control plane net-negative for small or delta work, and the prose-only assessment invited guessing — both against the cost-and-truthfulness goals of the control plane. |
| Impact | `library/workflow_router/contracts.py` (`ChangeSurface`, `UncertaintyLevel`, `RecoveryDifficulty`, `SecuritySurface`, `ExternalEffectSurface`, `WorkflowIntensity`, `WorkloadAssessment`, `derive_workflow_intensity`, `NormalizedGoal.workload`); `skills/johnny-project-takeover/references/delivery-profile.md` (typed assessment authority and the adaptive workflow-shape table); new `tests/test_workflow_intensity.py`. |
