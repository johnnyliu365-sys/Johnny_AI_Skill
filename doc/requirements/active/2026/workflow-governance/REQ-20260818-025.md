# Bounded Wayfinder information-gap protocol

| Field | Value |
| --- | --- |
| PRD / change | `PRD-20260818-025` / `CHG-20260818-025` |
| Lifecycle | `ACTIVE` |
| Old rule | Wayfinder's only legal returns were `WAYFINDER_GO` / `WAYFINDER_NO_GO`. "Ask before guessing" had no typed path: `WAIT_FOR_HUMAN` did not declare a Wayfinder question gate, so on incomplete requirements an Agent could only fabricate output fields or stall. |
| New rule | Wayfinder may additionally return one typed `WAYFINDER_INFO_REQUIRED` carrying a `WayfinderInfoRequest`: every currently blocking gap listed at once from the closed `WayfinderInputField` set, each gap naming the exact output field or strict-veto item it unblocks, answered fields never re-asked, round counter closed at `1 \| 2`. The Router suspends with declared wait reason `WAYFINDER_INPUT_GAP`; committed answers resume through `OWNER_INPUT_PROVIDED` re-entering `WAYFINDER`. Round exhaustion forces a terminal `GO` with explicit assumptions or `NO-GO / INSUFFICIENT_INPUT`. |
| Rationale | Convergence failure observed in live takeover use: with no legal insufficiency return, the model filled the Required Output with fabricated assumptions or oscillated indefinitely. The bounded typed protocol restores fail-closed truthfulness and guarantees a terminal state. |
| Impact | `library/workflow_router/contracts.py` (two `RouterEventKind` members, `WAYFINDER_INPUT_GAP` wait reason, `WAYFINDER_INFO_REQUEST` artifact kind, `WayfinderInputField` / `WayfinderBlockKind` / `WayfinderInputGap` / `WayfinderInfoRequest`); `library/workflow_router/profile.py` (two policy routes, two POC transition rules); `Defined_wayfinder.md`; `Workflow.md`; `references/router-control.md`; `references/discovery-change.md`; mirrored route expectations in `tests/test_workflow_router.py`; new `tests/test_wayfinder_info_gap.py`. |
