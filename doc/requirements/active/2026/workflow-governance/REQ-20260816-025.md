## Required behavior

1. New-project and takeover initialization binds one project-scoped architecture owner and later
   one project-scoped Senior. Implementers are activated only for admitted ticket work. One
   identity cannot be active in the same role across two projects.
2. A persistent project Implementer slot may keep a target-owned Context Library, but each model
   execution resolves only one immutable ticket `context_epoch_id`. Closed epochs remain indexed
   evidence and are never implicit input to a later ticket.
3. Johnny-owned project workspaces may use a shared append-only content-addressed seed/object
   pool with immutable baseline generations. Target repositories neither contain nor depend on
   that pool. Exact ownership and live-receipt references govern cleanup.
4. `LIGHT` and `STANDARD` resource classes have exact CPU, memory, disk, process, container,
   worker and lane caps. `HEAVY_APPROVAL` has no defaults. Local inference/training capacity is
   reserved before Johnny work and insufficient residual capacity stops the workflow without
   terminating the local model.
5. `TicketReceipt` is the only execution authority. `StageWorkReceipt` identifies
   Architecture/Grill/SPEC/Senior planning work but cannot authorize implementation or external
   effects. Heartbeat remains forbidden without separate explicit user approval.
6. Telemetry records provider input, cached input, optional cache-write input and output tokens,
   exact role/model/strength/tier/pricing metadata and receipt-bound evidence references.
   Missing provider data remains `NOT_REPORTED`; Agent estimates cannot replace it.
7. Report generation begins only on an explicit user request. A deterministic script follows
   the receipt to immutable Context/read/result/provider evidence, recalculates each item and
   emits aggregate terminal/Markdown/JSON/CSV/SVG output to stdout. Johnny never writes a report
   into a target project automatically.
8. The primary comparison uses the same Git snapshot and all eligible tracked text with Johnny
   Router/skill/Context-management inputs removed. It makes zero model calls, applies the stated
   equal-output and cache assumptions, and labels tokenizer/provider evidence and unobservable
   data without inventing actual usage.

## Impact and transition

- The four listed SPEC revisions replace only their explicitly named conflicting clauses after
  the project owner approves their exact text.
- Existing implementation, review and integration evidence remains immutable. The Senior's
  existing `UPSTREAM_DECISION_REQUIRED` leaves remain historical admission evidence and are not
  rewritten or silently promoted.
- This change authorizes architecture-owned documentation only. It creates no ticket, dispatch
  receipt, task, workspace, telemetry stream, installation, model execution or external effect.
