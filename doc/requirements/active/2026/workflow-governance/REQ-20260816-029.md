## Required behavior

1. `BPB-R03-00-20260816-001` binds only project `AI控制工作workflow`, ticket
   `R03-00-policy-correction-prerequisite`, closure `R03-00-CS-01`, registry commit
   `e0a710d217624cd90f902e14fe216d945e5ef0fa` and the exact ticket digest recorded by the bridge.
2. The Senior must independently approve the exact committed bridge before creating a bootstrap
   grant. The bridge itself creates no grant, owner task, worktree, branch, ContextView, model
   selection, attempt, receipt, dispatch or integration authority.
3. Each initial or correction host effect requires a separately committed and project-owner-
   approved one-shot grant followed by claim-before-effect. User relay is only a wake hint.
4. `EFFECT_UNCERTAIN` quarantines the bridge route without retry. Requirement change or ticket
   defect returns to Architecture. Reviewed R03-00 integration permanently closes the bridge.
5. R03-01A through R03-01D remain blocked until R03-00 is independently reviewed and integrated;
   each later phase still requires its own exact grant and predecessor proof.
6. The bridge does not claim that the executable Router allowlist, receipt issuer, host gateway or
   supervision chain already exists. It permits only the bounded manual self-host action needed
   to implement and review that policy.
7. Heartbeat, automation, cron, watchdog, active-turn waiting, recurring thread/Git/filesystem
   reads, timed polling, push, release and deployment remain forbidden.
