## Non-negotiable properties

1. A generated Level 1 tree contains no path under `library/local_orchestration/` and no
   `install.ps1` or `johnny-install.cmd`; adding any of those to the declaration is a red
   topology-boundary test.
2. The surviving declared library paths are segment-exact, reachable from the installed skill or
   reusable-module catalog, and retain closed Markdown-reference and Python-import checks.
3. A plugin cannot claim a host capability merely because development source contains it. The
   installed Claude payload carries policy and reusable source only; host registration, runner,
   installer, publication, cache inspection and external effects remain outside it.
4. The Level 2 package manifest and its independently owned `_PAYLOAD_TREE_ROOTS` remain
   unchanged. This is a Level 1 declaration/topology change only.
5. No source candidate, tag or release may be repinned under `plugin-v0.4.10`. F3 has no remote,
   user-cache, Claude CLI, repository, ref, tag, release or push effect.
6. Ticket 08 remains blocked. Only an owner-selected successor version, recorded after F3
   integration, may re-open its release-admission path.
