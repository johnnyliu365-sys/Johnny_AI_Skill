## Non-negotiable properties

1. A direct same-lifetime lane must not be blocked by the absence of cross-lifetime machinery.
2. Native delegation is permitted only for the reviewer after ticket admission; an implementation owner cannot control another agent.
3. The parent waits for completion without activity/status polling. It never claims an asynchronous wake, runner delivery, or receipt it did not observe.
4. A missing host capability is a named halt, never a fallback to reviewer implementation or a fabricated adapter.
5. The published `0.4.14` payload and its Codex installed cache must contain the corrected command, skill and reference at the same release version.
