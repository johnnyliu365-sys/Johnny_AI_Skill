## Change record

| Field | Value |
| --- | --- |
| Old rule | Artifact-tree policy and the delivered resolver reject an invalid edge when a consumer resolves a path. `TargetDocumentPlan` can nevertheless create or update an explicit set of document paths without proving that a new or changed leaf and its direct-parent edge are one atomic logical mutation. Agents can therefore create a formally named document and forget its index until a later reader discovers the orphan. |
| New rule | The normal write surface is a provider-neutral managed-artifact operation. Its pure planner derives a finite leaf-plus-parent mutation plan from exact caller-selected metadata; its target writer applies that plan atomically against an exact baseline; and the existing resolver validates the resulting selected path before success is exposed. Host adapters reinforce the behavior but never replace repository admission. |
| Rationale | Instruction text can be skipped, shortened or absent from a later session. Making the valid index update part of the only successful operation gives the Agent a stable action/result loop: the correct action succeeds, supported raw writes fail, and an invalid stop routes to bounded repair. |
| Impact | Revise the existing Adaptive Project Orchestration Context/SPEC after owner acceptance; extend strict document contracts, the target document transaction, candidate admission and tests; add one Codex plugin behavior adapter and installed qualification; then publish a separately authorized plugin patch release. No implementation, hook installation, publication or target-project mutation is authorized by this requirement leaf. |
| Security / privacy | Hook inputs and shell/edit payloads are untrusted ephemeral input. A classifier may derive only normalized repository-relative path metadata and finite reason codes; it must not execute, persist, log or return raw command text, transcript content, secrets, URIs or absolute target paths. |

## Non-negotiable properties

1. The behavior is procedural, not a claim that a model acquired durable neural memory.
2. Artifact quantity remains delivery-profile-scaled. The mechanism maintains every artifact that
   is required or intentionally created; it does not invent extra documents to satisfy ceremony.
3. A planner receives one selected artifact path and its exact parent chain. It must not scan,
   flatten or materialize unrelated branches to discover where a document might belong.
4. `CREATE`, `REVISE`, `REPLACE` and `ARCHIVE` have distinct finite contracts. A leaf-content
   digest or lifecycle change requires the matching direct-parent edge change in the same plan.
5. A plugin-provided host hook is a guardrail only. Missing, disabled, untrusted or unsupported
   hook coverage must be reported honestly and cannot weaken the repository-level gate.
6. A `Stop` continuation is bounded by the host's re-entry marker. It must not create an infinite
   self-correction loop or report a repair it did not observe.
7. Plugin detach removes the behavior adapter and control-plane tooling only. Target-owned
   documents and indexes remain unchanged and usable without a plugin runtime dependency.
