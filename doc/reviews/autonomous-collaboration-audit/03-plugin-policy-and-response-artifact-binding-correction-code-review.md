### CR-27 — Missing reviewed commit references still grant dispatch capability

**Impact:** both commit fields remain optional on `ImplementationHandoff` and `PendingDispatchDescriptor`. The Router creates a pending human wait with both values absent; although rendering halts, a caller that has the descriptor can submit a matching receipt and obtain `AUTO_RUN`. Missing committed-artifact evidence therefore fails open into implementation authority rather than failing closed, contrary to the required source-validation rule and the fixed-response policy.

**Independent reproduction:** a `TICKET_DISPATCH_REQUIRED` request whose handoff had `ticket_docs_commit=None` and `handoff_docs_commit=None` returned `missing_commit_wait=wait_for_human`; its matching positive receipt returned `missing_commit_confirmation=auto_run`.

**Evidence:** `library/workflow_router/contracts.py:322-323,404-405` declares both values optional; `router.py:234-244` copies them without a required-source guard; `private_router.py:895-904` only blocks them at render time.

**Required correction:** reject the dispatch request before any pending descriptor, human question, receipt validation or ticket-lane capability is created when either reviewed commit reference is missing. Add a red/green direct and private-client regression proving missing ticket commit, missing handoff commit and both missing values halt with no response and no `AUTO_RUN` / implementation grant.

**Impact:** the current ticket explicitly requires seven cases: exactly equal, one-extra-character prefix, trailing slash, casing, URL encoding, `..` traversal and empty value. It also does not cover the ticket's required null, `undefined` equivalent, empty string, whitespace and empty-container representations. The test count is therefore not evidence that the specified boundary cases are protected.

**Evidence:** `tests/test_plugin_policy_and_response.py:350-368` has seven different locator strings, but not the required variants. The current ticket TDD item 6 lists the required cases individually.

**Required correction:** replace or extend that test with one independently asserted subtest for each named boundary variant and the five missing-value cases. For every case prove no formatting output, pending descriptor, receipt acceptance or capability grant can result.
