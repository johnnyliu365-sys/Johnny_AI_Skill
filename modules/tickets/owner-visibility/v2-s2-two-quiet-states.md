# V2-S2 — 兩個安靜的狀態要能不靠顏色分辨

| Field | Value |
| --- | --- |
| State | 排隊中，等 V2-S1 完成 |
| Owner | UI implementation owner |
| Files | `library/local_orchestration/ticket_status_template.py` 與它的測試 |
| Depends on | V2-S1（色票定案前不要動） |

## 一個結果

`APPROVED` 和 `IN_PROGRESS` 不再只差顏色。

## 為什麼這是一張票

你自己連續兩輪提出這個缺口：三個需要人動手的狀態都已經有形狀差異（三角形、填滿、色條），但這兩個「不需要動作」的狀態只差藍與綠。對於分不出這兩個色相的人，這頁有兩種狀態是同一種。

風險低不代表不用做——這頁的全部價值就是不用讀字也能分辨，留一半不成立就是留一半。

## 邊界

不要動任何已定案的顏色。差異要來自形狀、邊框、位置或密度，不是換色。也不要把 `APPROVED` 做得比需要人動手的狀態更搶眼——已經通過的東西應該是頁面上最安靜的。

## 驗收

| Ref | 要求 | 證據 |
| --- | --- | --- |
| S2-1 | 兩個狀態有顏色以外的差異 | 結構斷言，不是文案斷言 |
| S2-2 | 五種狀態在灰階下仍兩兩可分 | 測試：把顏色資訊拿掉之後仍有區別 |
| S2-3 | `APPROVED` 不比任何需要動作的狀態搶眼 | 沿用你既有的響度斷言 |
| S2-4 | 反向突變 | 移除新增的差異，S2-1 要轉紅 |
